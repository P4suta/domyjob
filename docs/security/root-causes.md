# Root causes and the mechanisms that close them

Every review finding is traced to a class of mistake, and every class is closed by a mechanism that makes the mistake unwritable, not by a patch at the site that was found.
A finding is only resolved when its class has a mechanism and a test that would fail if the class came back.

| Class | What made it writable | Mechanism | Enforced by |
| --- | --- | --- | --- |
| RC-A. Trust decided by plain values | `bool` for "paired", `Option` for "has checksum", `Option<psk>` choosing a Noise pattern, pinning as a separate step | Proof types with private constructors: `Verified<T>`, `Authorized<R>`, `Channel` returned only after the peer matched an `Expect` | Rust privacy; handlers accept only the proof type |
| RC-B. Unbounded resources | `read_line`, `read_to_end`, `thread::spawn` per accept | Bounded readers with a byte budget, and a connection `Permit` counted overall and per source address | `clippy.toml` disallows the unbounded std calls outside `bounded.rs` |
| RC-C. Ambiguous stream end | Raw EOF and an authenticated close meant the same thing | `Frame::{Data, Close}` inside the ciphertext and a reader state machine `Open, Closed` | Exhaustive match on the frame enum |
| RC-D. Secrets in ordinary types | `Vec<u8>` secret with derived `Debug` and `Clone` | `Secret<T>`: no `Clone`, redacted `Debug`, zeroized on drop | The gate refuses `Debug`/`Clone` derives on types holding `Secret` |
| RC-E. State files written ad hoc | `fs::write` with default permissions, read-modify-write races | One `StateFile<T>`: owner-only directory and file, permission check on read, atomic replace, a lock around updates | `clippy.toml` disallows `fs::write`, `fs::read`, `File::create` outside `state_file.rs` |
| RC-F. Untrusted content reaching sinks | Remote names, logs, and repository files flowed as `String`/`Vec<u8>` into terminals, config, and target selection | `Untrusted<T>` for everything a peer or repository supplies; leaving it needs a named neutralizer (`for_terminal`, `as_machine_name`) | Wire and repository types deserialize into `Untrusted` |
| RC-G. Mutable external references | `latest`, action tags, `curl \| sh`, a checksum from the same origin | A signed release manifest verified against keys compiled into the binary, version monotonicity, workflows pinned by digest | `Verified<Binary>` required by install and update; gates over `.github/` |
| RC-H. All-or-nothing authority with no lifecycle | Pairing implied full remote execution, nothing could be listed, revoked, or audited | `Grant` with a set of `Capability`, an exhaustive `decide`, revocation, and a hash-chained audit log | `decide` has no wildcard arm; `wildcard_enum_match_arm` is denied crate-wide |
| RC-I. Dangerous defaults | `0.0.0.0` default bind, discovery always on, running as root | `Exposure::{Loopback, Tailnet, Lan, Explicit}` with the risky variants requiring an explicit argument; refusal to run elevated | The listener accepts only `Exposure`, never a raw address |
| RC-J. No human in the loop where only a human can decide | Pairing enrolled a key without confirmation | A short authentication string shown on both sides and confirmed before any grant is written | The grant constructor takes a `Confirmed` token |
| RC-K. Repository content choosing policy | A pushed `domyjob.toml` picked targets, commands, and environment | Policy comes only from local configuration; repository files may request, never grant | `LocalPolicy` and `RepositoryRequest` are distinct types |
| RC-L. Untrusted values in argument positions | `curl -d {message}` let a server-chosen `@path` read a local file | Template bindings are typed by trust; untrusted values have no path into an argv and reach external programs only on stdin | `Bindings` for argv accept only `Trusted` values |
| RC-M. Hand-made concurrency | Lock files taken with `create_new` and stolen by inferring liveness from heartbeats | Operating-system file locks only, released by the kernel when the holder dies; a supervisor holds its job's lock for its whole life, so "alive" is a fact the kernel keeps | `clippy.toml` disallows `OpenOptions::create_new` outside `lock.rs` |
| RC-N. Escaping written per language by hand | PowerShell's typographic quotes and cmd's `%VAR%` were missed | Each quoting rule is an exhaustive classification of every character, with property tests over arbitrary strings | Tests round-trip every rule through the real interpreter where available |
| RC-O. Identifiers chosen by the less trusted side | Job ids came from the client; warm workspaces were shared across trust levels | The node assigns job ids and records the submitting principal; workspaces are keyed by project and trust level | `JobId::generate` is callable only from the node |
| RC-Q. Partial results passing as whole ones | A stream cut by the network ended in EOF and was taken as the end of the file or the log; an error after the reply had started was written into the user's file | Every stream is framed: chunks, then an ending that carries the byte count and a BLAKE3 digest or the sender's refusal; no ending means "cut" | `framed::unframe` is the only reader of streamed replies, and its property test cuts every payload at every offset |
| RC-R. Crashes leaving state that blocks the next run | An audit entry written without its head, a workspace half filled, a job whose supervisor died, a staging directory never published, a slot that cannot be cleared | Each record is written so the next reader can finish or undo it: repair under the audit lock, intent recorded before filling, a sweep on every request that acts only on what a free lock proves abandoned, and a trash area for what cannot be removed in place | Tests that cut each write at its crash points and run the next request |
| RC-S. A full disk that stops everything | A job's log filled the disk; after that every command failed on a small record it wanted to rewrite, including the ones that only read, and nothing gave space back | Reads never depend on a write: an audit head that cannot be saved is used from memory, and the client rewrites its records only when they change and warns when it cannot; the sweep gives back space in the order that loses least, idle workspaces, then the largest finished logs, then sources that only finished jobs used, and never a job record; a full disk is reported as such | Tests make the audit head unwritable, drive the sweep with the disk reported short, and classify a full disk however deeply it is wrapped; a live test fills a small tmpfs and checks that reading, recovery, and history all survive |
| RC-P. Time used as evidence | A heartbeat older than 15 seconds meant "dead", sleeps polled for kill requests and free slots, a grace period separated SIGTERM from SIGKILL, mtimes meant "unchanged", pairing codes, grants, and release manifests expired, handshakes had deadlines | Every such question is answered by the event itself: a held lock for liveness, a blocking lock for a free slot, a local socket for kill, wait, and log delivery, a pipe or kernel event for "the supervisor started", content hashes for "unchanged", counts for pairing attempts and connections, explicit revocation for grants, a version high-water mark for releases | `clippy.toml` disallows every clock, sleep, timeout, and file timestamp API; the gate refuses time types and timeout methods everywhere, tests included; the wall clock is read only by `clock::Timestamp::observe`, whose type has no ordering; the single exception, a silent peer, lives in `liveness.rs` and decides only whether to give up a connection |

## Crate-wide lint escalations

The classes above share one habit: a default branch or a default value silently decided a security question.
So the crate also denies `clippy::wildcard_enum_match_arm`, `clippy::match_wildcard_for_single_variants`, and `clippy::fallible_impl_from`, and the gate refuses `#[derive(Default)]` on any type in a security module.
