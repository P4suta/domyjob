# Root causes and required mechanisms

Every review finding is traced to a class of mistake.
The table states the mechanism and check required to close each class; naming them here does not establish that they are implemented.
A class is closed only when the production API prevents the unsafe flow, a build gate rejects bypasses, and a test exercises the property at its boundary.
The implementation status of the seven overarching laws is recorded in [laws.md](laws.md).

| Class | What made it writable | Required mechanism | Required check |
| --- | --- | --- | --- |
| RC-A. Trust decided by plain values | `bool` for "paired", `Option` for "has checksum", `Option<psk>` choosing a Noise pattern, pinning as a separate step | Proof types with private constructors: `Verified<T>`, `Authorized<R>`, `Channel` returned only after the peer matched an `Expect` | Rust privacy; handlers accept only the proof type |
| RC-B. Unbounded resources | `read_line`, `read_to_end`, `fs::read`, `read_to_string`, child `.output()`, `thread::spawn` per accept | Bounded readers, file loads, and child output with explicit byte budgets, streaming for large blobs, and a connection `Permit` counted overall and per source address | The syntax gate rejects unbounded stream, text, binary file, and child output reads outside `bounded.rs`; tests exercise the size boundaries, concurrent child pipes, and streamed content verification |
| RC-C. Ambiguous stream end | Raw EOF and an authenticated close meant the same thing | `Frame::{Data, Close}` inside the ciphertext and a reader state machine `Open, Closed` | Exhaustive match on the frame enum |
| RC-D. Secrets in ordinary types | `Vec<u8>` secret with derived `Debug` and `Clone` | `Secret<T>`: no `Clone`, redacted `Debug`, zeroized on drop | The gate refuses `Debug`/`Clone` derives on types holding `Secret` |
| RC-E. State files written ad hoc | `fs::write` with default permissions, read-modify-write races | One `StateFile<T>`: owner-only directory and file, permission check on read, atomic replace, a lock around updates | Clippy disallows `fs::write` and `File::create`, the syntax gate disallows ordinary `fs::read`, and a typed locked state file now owns JSON updates and release high-water state |
| RC-F. Untrusted content reaching sinks | Remote names, logs, and repository files flowed as `String`/`Vec<u8>` into terminals, config, and target selection | `Untrusted<T>` for everything a peer or repository supplies; leaving it needs a named neutralizer (`for_terminal`, `as_machine_name`) | Wire and repository types deserialize into `Untrusted` |
| RC-G. Mutable external references | `latest`, action tags, `curl \| sh`, a checksum from the same origin | A signed release manifest verified against keys compiled into the binary, version monotonicity, workflows pinned by digest | `Verified<Binary>` required by install and update; gates over `.github/` |
| RC-H. All-or-nothing authority with no lifecycle | Pairing implied full remote execution, nothing could be listed, revoked, or audited | `Grant` with a set of `Capability`, an exhaustive `decide`, revocation, and a hash-chained audit log | `decide` has no wildcard arm; `wildcard_enum_match_arm` is denied crate-wide |
| RC-I. Dangerous defaults | `0.0.0.0` default bind, discovery always on, running as root | `Exposure::{Loopback, Tailnet, Lan, Explicit}` with the risky variants requiring an explicit argument; refusal to run elevated | The listener accepts only `Exposure`, never a raw address |
| RC-J. No human in the loop where only a human can decide | Pairing enrolled a key without confirmation | A short authentication string shown on both sides and confirmed before any grant is written | The grant constructor takes a `Confirmed` token |
| RC-K. Repository content choosing policy | A pushed `domyjob.toml` picked targets, commands, and environment | Policy comes only from local configuration; repository files may request, never grant | `LocalPolicy` and `RepositoryRequest` are distinct types |
| RC-L. Untrusted values in argument positions | `curl -d {message}` let a server-chosen `@path` read a local file | Template bindings are typed by trust; untrusted values have no path into an argv and reach external programs only on stdin | `Bindings` for argv accept only `Trusted` values |
| RC-M. Hand-made concurrency | Lock files taken with `create_new` and stolen by inferring liveness from heartbeats | Operating-system file locks only, released by the kernel when the holder dies; a supervisor holds its job's lock for its whole life, so "alive" is a fact the kernel keeps | Clippy rejects `OpenOptions::create_new` by default, and the syntax gate permits it only in four named functions that create ordinary files; `lock.rs` has no exception |
| RC-N. Escaping written per language by hand | PowerShell's typographic quotes and cmd's `%VAR%` were missed | Each quoting rule is an exhaustive classification of every character, with property tests over arbitrary strings | Tests round-trip every rule through the real interpreter where available |
| RC-O. Identifiers chosen by the less trusted side | Job ids came from the client; warm workspaces were shared across trust levels | The node assigns job ids and records the submitting principal; workspaces are keyed by project and trust level | `JobId::generate` is callable only from the node |
| RC-Q. Partial results passing as whole ones | A stream cut by the network ended in EOF and was taken as the end of the file or the log; an error after the reply had started was written into the user's file | Every stream is framed: chunks, then an ending that carries the byte count and a BLAKE3 digest or the sender's refusal; no ending means "cut" | `framed::unframe` is the only reader of streamed replies, and its property test cuts every payload at every offset |
| RC-R. Crashes leaving state that blocks the next run | An audit entry written without its head, a workspace half filled, a job whose supervisor died, a staging directory never published, a slot that cannot be cleared | Each record is written so the next reader can finish or undo it: repair under the audit lock, intent recorded before filling, a sweep on every request that acts only on what a free lock proves abandoned, and a trash area for what cannot be removed in place | Tests that cut each write at its crash points and run the next request |
| RC-S. A full disk that stops everything | A job's log filled the disk; after that every command failed on a small record it wanted to rewrite, including the ones that only read, and nothing gave space back | Reads never depend on a write: an audit head that cannot be saved is used from memory, and the client rewrites its records only when they change and warns when it cannot; the sweep gives back space in the order that loses least, idle workspaces, then the largest finished logs, then sources that only finished jobs used, and never a job record; a full disk is reported as such | Tests make the audit head unwritable, drive the sweep with the disk reported short, and classify a full disk however deeply it is wrapped; a live test fills a small tmpfs and checks that reading, recovery, and history all survive |
| RC-P. Time used as evidence | A heartbeat older than 15 seconds meant "dead", sleeps polled for kill requests and free slots, a grace period separated SIGTERM from SIGKILL, mtimes meant "unchanged", pairing codes, grants, and release manifests expired, handshakes had deadlines | Every such question is answered by the event itself: a held lock for liveness, a blocking lock for a free slot, a local socket for kill, wait, and log delivery, a pipe or kernel event for "the supervisor started", content hashes for "unchanged", counts for pairing attempts and connections, explicit revocation for grants, a version high-water mark for releases | `clippy.toml` disallows every clock, sleep, timeout, and file timestamp API; the gate refuses time types and timeout methods everywhere, tests included; the wall clock is read only by `clock::Timestamp::observe`, whose type has no ordering; the single exception, a silent peer, lives in `liveness.rs` and decides only whether to give up a connection |
| RC-T. Host-only type checks and reusable build artifacts | A new private argument type compiled on macOS but had no import in a Windows-only module; Windows PowerShell 5.1 returned `null` for `Start-Process.ExitCode` after a manual wait, and the falsey value let a failed build stage the previous executable from a shared Cargo target directory | The CI matrix compiles every target on each supported operating system; a source build runs Cargo directly in a PowerShell job and checks its native exit code and job state, builds in a target directory keyed by the client build stamp and source archive hash, requires an executable, and verifies its embedded source stamp before promotion | Windows Clippy covers the platform module; Windows tests build valid and invalid source with an old executable present, require failure to stage nothing, and require success to stage a new executable |
| RC-U. Operation identity confused with session identity | A process-wide session name was used for Windows upload files, so two builds in one process overwrote and deleted each other's base64 input; the Cargo target and incoming executable were also shared | A private `TransferId` wraps a fresh random `Nonce`, and setup fails if entropy fails; typed remote commands carry that ID through upload, build output, verification, promotion, and best-effort cleanup on error; the build target is also keyed by the source archive's `BlobId` | Rust signatures require an ID for every setup command; the syntax gate rejects a fixed incoming filename; Windows tests build two different sources concurrently in one cache, run both staged executables, and promote each one by its own ID |
| RC-V. Test failures shared process-global injection state | `fail::cfg` and a single crash slot let parallel tests clear or replace each other's fault plan; an empty path tag injected `pull::swap` faults into unrelated tests | Test guards register rules independently by ID and remove only their own rules on drop; `inject_after` requires an absolute `Path` scope and counts only matching operations; crash guards are also scoped by path | Clippy bans direct `fail::cfg` and the syntax gate confines process-global scenario setup to `faults.rs`; concurrent tests arm the same site under separate paths and prove unrelated paths remain unaffected; the full test suite runs in parallel on each supported operating system |
| RC-W. One identifier served unrelated resource limits | Making the process session ID long enough for transfer filenames also lengthened OpenSSH `ControlPath` beyond macOS's Unix socket limit, so source setup could not even probe Windows | `SshSessionId` is separate from `TransferId`, uses a short random value, and fails closed if entropy fails; each rendered SSH control path is checked against the platform socket limit before launching SSH | A unit test checks the SSH ID length and rejects an overlong path; an end-to-end source setup from macOS to Windows exercises the rendered default transport |
| RC-X. Recursive wildcard matching on unbounded strings | A local trigger's `refs` patterns and a hook's `--ref` entered as plain `String`; every `*` branched over every remaining character, so a crafted pattern and ref could consume exponential CPU | `RefPattern` and `EventRef` reject values beyond 1024 bytes and control characters at deserialization and CLI parsing; matching scans ordered literal segments without recursion | The syntax gate requires the typed fields, boundary tests enforce the byte budget, and a property test compares matching against an independent dynamic programming oracle |
| RC-Y. A snapshot retained an ambient source path | `Origin::Disk(PathBuf)` reopened an absolute path after the source was inspected, so replacing a parent directory with a link could redirect later reads outside the selected root | A private `DiskOrigin` retains the directory handle opened before inspection and a validated `RelPath`; archive and upload read only through that handle, stream within explicit budgets, and check the captured digest | Rust privacy prevents constructing a disk origin from a plain path; a test swaps an intermediate directory for an external link and requires archive creation to fail |

## Crate-wide lint escalations

The classes above share one habit: a default branch or a default value silently decided a security question.
So the crate also denies `clippy::wildcard_enum_match_arm`, `clippy::match_wildcard_for_single_variants`, and `clippy::fallible_impl_from`, and the gate refuses `#[derive(Default)]` on any type in a security module.

## Known open classes

RC-B remains open because other allocating reads and thread-spawn paths still need an end-to-end resource audit; network connections have overall and per-source permits, local control connections have a 32-session permit, source archives are capped at 64 MiB, child output has per-purpose budgets, and blobs are streamed when they may be larger.
RC-E remains open because most state operations still accept plain paths; `StateFile<T>` now provides a typed locked capability for JSON updates and the release high-water mark, but other state files have not been migrated.
RC-F and RC-L remain open because source-specific argument types cover only some flows; wire and repository values do not yet carry a general provenance label, and `Arg::path` still accepts an ordinary `Path`.
RC-K remains open because the code does not yet have distinct `LocalPolicy` and `RepositoryRequest` types.
